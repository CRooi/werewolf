# 狼人杀（H5 远程版）

玩家各自在手机上打开网页，由法官推进流程，适合大家在语音通话中远程开局。

- 前端：React + Vite + Tailwind + shadcn（根目录）
- 后端：Express + ws + SQLite（`api/`，运行于 Bun）
- 共享类型：`shared/types.ts`

## 开发

```bash
bun install && bun install --cwd api
bun run dev:api   # 后端 http://localhost:3001（watch 模式）
bun run dev       # 前端 http://localhost:5173，/api 与 /ws 代理到后端
```

同一局域网的手机访问 `http://<电脑IP>:5173` 即可加入。

## 大屏

打开 `/?overview=房间码`（或 `/?overview` 后输入房间码），适合投到电视/投影上给所有人看：

- 圆桌展示座位、存活与夜间闭眼状态，中央显示当前阶段，侧栏是公告记录
- 投票时实时显示每个人投给谁（实线为已确认、虚线为未确认）和确认进度
- 天亮死讯、放逐、猎人开枪会全屏弹出几秒后自动收起
- 只包含所有人可见的信息；公布结果后才展示全员身份与完整复盘

## 调试台（多玩家测试）

打开 `http://localhost:5173/?debug`（开发环境首页底部也有入口）：

- 一键开局：槽位 0 建房当法官，其余座位自动坐满
- 加入已有房间：按房间码补满空位或逐个加人
- 每个槽位对应一个 `?slot=N` 的标签页，身份存储互相独立，标签页标题显示 `[N] 名字`
- 「全部打开」需要允许本站弹出窗口；生产构建设置 `VITE_DEBUG=1` 可在首页显示入口

## 测试

```bash
bun run test      # 游戏引擎单元测试
```

## 部署

```bash
bun run build     # 产出 dist/
bun run start     # 后端同时托管 dist/，默认端口 3001（PORT 环境变量可改）
```

## 规则说明

- 法官不占座位，座位数 = 各身份数量之和；开局前可换座、与法官互换身份
- 狼人需全部（存活的）睁眼后才能选择猎杀对象，意见统一后才能确定，可自刀、可空刀
- 女巫解药用完后不再得知死讯；是否可同晚双药、是否可自救由建房时配置
- 猎人被狼人杀死或被投票放逐可开枪，被毒杀不可开枪
- 白痴（神职）被投票放逐时可选择亮明身份免于出局一次，此后不能投票也不能被投票；夜间死亡照常出局
- 平票时法官选择：PK 重投（PK 玩家本人不投票）、指定出局或无人出局
- 屠边规则：狼人全灭好人胜；神职全灭或平民全灭狼人胜，同时满足时狼人胜
- 已出局的神职，法官仍需照常走睁眼/闭眼流程，避免泄露信息
